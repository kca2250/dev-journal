# 共通仕様

全機能に共通する仕様。

## 多言語対応

### ヘルプ・メッセージの言語

- `LANG` 環境変数に応じて自動切替
- `ja_JP` の場合は日本語、それ以外は英語
- 対象: ヘルプメッセージ、エラーメッセージ、確認メッセージ

### 実装方針

```go
func isJapanese() bool {
    lang := os.Getenv("LANG")
    return strings.HasPrefix(lang, "ja")
}
```

## カラー出力

### TTY自動検出

- ターミナル（TTY）に出力している場合のみカラー出力を有効化
- パイプやファイルリダイレクト時は自動で無効化
- 明示的な `--no-color` オプションは提供しない

### 実装方針

```go
import "github.com/mattn/go-isatty"

func useColor() bool {
    return isatty.IsTerminal(os.Stdout.Fd())
}
```

## 終了コード

### 統一ルール

| 終了コード | 意味 |
|------------|------|
| 0 | 正常終了 |
| 1 | エラー終了（全エラー共通） |

### エラー種別によるコード分けは行わない

- シンプルさを優先
- エラー内容はメッセージで判断

## データベース

### 保存場所

- `~/.djou/djou.db`
- ディレクトリが存在しない場合は自動作成

### 初期化

- 起動時にテーブルが存在しない場合は自動作成
