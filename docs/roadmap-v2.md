## Phase 8: MCP Server 機能 (djou mcp)

### 概要

Claude Code などの MCP クライアントから djou の機能を直接利用できるようにする。

### 仕様書

[feature-mcp.md](./feature-mcp.md)

### 実装内容

| ファイル | 内容 |
|----------|------|
| `internal/cmd/mcp.go` | mcp サブコマンド |
| `internal/mcp/server.go` | MCP サーバー初期化 |
| `internal/mcp/tools.go` | Tools 定義・ハンドラー |

### 詳細タスク

- [ ] mcp-go ライブラリの導入
- [ ] `mcp` サブコマンドの追加
- [ ] MCP サーバーの初期化処理
- [ ] `djou_record` Tool の実装
- [ ] `djou_list` Tool の実装
- [ ] `djou_search` Tool の実装
- [ ] `djou_stats` Tool の実装
- [ ] `djou_export` Tool の実装
- [ ] エラーハンドリングの実装
- [ ] Claude Code での動作確認

### 完了条件

- `djou mcp` で MCP サーバーが起動する
- 5つの Tools が全て動作する
- Claude Code から呼び出して記録・取得ができる
- エラー時に適切なレスポンスを返す
- 単体テストが通る

### 依存

- Phase 1〜7 の全機能（既存の Repository を再利用）
