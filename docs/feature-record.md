# 記録機能 (djou)

対話形式で開発日誌を記録する機能。

## コマンド

```bash
djou
```

## 機能要件

### FR-1: 対話形式での入力

ユーザーに対話形式で以下の項目を順番に入力させる。

| 項目 | 必須 | 型 | 説明 | バリデーション |
|------|------|-----|------|----------------|
| タスク名 | ⭕ | string | 作業したタスクの名前 | 空文字不可 |
| 見積もり(h) | ⭕ | float | 見積もり時間（時間単位） | 正の数値 |
| 実績(h) | ⭕ | float | 実際にかかった時間（時間単位） | 正の数値 |
| AI活用(min) | ❌ | int | AI活用した時間（分単位） | 0以上の整数、デフォルト0 |
| ハマったこと | ❌ | string | 作業中にハマった問題 | 空文字許可 |
| 解決方法 | ❌ | string | どう解決したか | 空文字許可 |
| 学び | ❌ | string | 得られた知見・気づき | 空文字許可 |

**任意項目のスキップ**: Enterキーで空入力としてスキップ

### FR-2: 日時の自動記録

- 記録時に`created_at`を自動で現在日時に設定する
- タイムゾーンはローカル時刻を使用

### FR-3: 記録完了の通知

記録が成功した場合、完了メッセージを表示する。

## 対話フロー

```
$ djou

? タスク名: ログイン画面実装
? 見積もり(h): 2
? 実績(h): 3
? AI活用(min): 30
? ハマったこと: CORSエラー
? 解決方法: プロキシ設定を追加
? 学び: API連携は早めに確認する

✅ 記録しました！
```

## 技術仕様

### 使用ライブラリ

- `github.com/charmbracelet/huh` - 対話UIフォーム

### データベース操作

- `logs`テーブルにINSERT

### エラーハンドリング

| エラー | 対応 |
|--------|------|
| DB接続失敗 | エラーメッセージを表示して終了（exit 1） |
| 入力キャンセル(Ctrl+C) | 「記録を中断しますか？」の確認メッセージを表示後、記録せずに終了 |
| バリデーションエラー | 該当項目の再入力を促す |
