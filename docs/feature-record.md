# 記録機能 (djou)

対話形式で開発日誌を記録する機能。

## コマンド

```bash
djou                                          # 対話形式で記録
djou record -t "タスク" -e 2 -a 3             # Quick Record（必須項目のみ）
djou record -t "タスク" -e 2 -a 3 -m "メモ" --tag "project:A"  # Quick Record（全項目）
```

## 機能要件

### FR-1: 対話形式での入力

ユーザーに対話形式で以下の項目を順番に入力させる。

| 項目 | 必須 | 型 | 説明 | バリデーション |
|------|------|-----|------|----------------|
| タスク名 | ⭕ | string | 作業したタスクの名前 | 空文字不可 |
| 見積時間(h) | ⭕ | float | 見積もり時間（時間単位） | 正の数値 |
| 実績時間(h) | ⭕ | float | 実際にかかった時間（時間単位） | 正の数値 |
| メモ | ❌ | string | 作業に関するメモ（複数行可） | 空文字許可 |
| タグ | ❌ | string | カンマ区切りのタグ | 空文字許可 |

**任意項目のスキップ**: Enterキーで空入力としてスキップ

### FR-2: Quick Record モード

`-t`, `-e`, `-a` の必須フラグが全て指定された場合、対話フォームを表示せず即時記録する。

| フラグ | 短縮形 | 必須 | 説明 |
|--------|--------|------|------|
| --task | -t | ⭕ | タスク名 |
| --estimate | -e | ⭕ | 見積もり時間 |
| --actual | -a | ⭕ | 実績時間 |
| --memo | -m | ❌ | メモ |
| --tag | - | ❌ | タグ（カンマ区切り） |

### FR-3: 日時の自動記録

- 記録時に`created_at`を自動で現在日時に設定する
- タイムゾーンはローカル時刻を使用

### FR-4: 記録完了の通知

記録が成功した場合、完了メッセージを表示する。

## 対話フロー

```
$ djou

? タスク名: ログイン画面実装
? 見積時間 (h): 2
? 実績時間 (h): 3
? メモ: CORSエラーでハマった。プロキシ設定で解決。
? タグ: task_type:新機能, project:案件A

✅ ログを記録しました
```

## 技術仕様

### 使用ライブラリ

- `github.com/charmbracelet/huh` - 対話UIフォーム

### データベース操作

- `logs`テーブルにINSERT

### エラーハンドリング

| エラー | 対応 |
|--------|------|
| DB接続失敗 | エラーメッセージを表示して終了（exit 1） |
| 入力キャンセル(Ctrl+C / Esc) | 記録せずに終了 |
| バリデーションエラー | 該当項目の再入力を促す |
