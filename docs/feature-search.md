# 検索機能 (djou search)

キーワードで開発日誌を検索する機能。

## コマンド

```bash
djou search "キーワード"
```

## 機能要件

### FR-1: キーワード検索

以下のフィールドからキーワードを検索する。

- タスク名 (task_name)
- ハマったこと (problem)
- 解決方法 (solution)
- 学び (learning)

### FR-2: 部分一致検索

- 大文字・小文字を区別しない
- 部分一致で検索
- **複数キーワード**: スペース区切りで複数キーワードを指定した場合はAND検索（全キーワードを含む記録のみマッチ）

### FR-3: 検索結果の表示

マッチした記録をテーブル形式で表示する。

| カラム | 説明 |
|--------|------|
| 日付 | 記録日 |
| タスク | タスク名 |
| マッチ箇所 | どのフィールドでマッチしたか |

### FR-4: 詳細表示

検索結果を選択すると詳細を表示する。

**初期リリースに含める**: 検索結果から選択して詳細情報（全フィールド）を表示可能

### FR-5: 検索結果の件数制限

- デフォルトは無制限
- `--limit` オプションで表示件数を制限可能

## 出力例

```
$ djou search "CORS"

🔍 検索結果: 2件

┌────────────┬──────────────────┬──────────────┐
│ 日付       │ タスク           │ マッチ箇所   │
├────────────┼──────────────────┼──────────────┤
│ 2025-01-10 │ ログイン画面実装 │ ハマったこと │
│ 2025-01-08 │ API実装          │ 学び         │
└────────────┴──────────────────┴──────────────┘
```

## 技術仕様

### コマンド引数

| 引数 | 必須 | 説明 |
|------|------|------|
| keyword | ⭕ | 検索キーワード（スペース区切りで複数指定可、AND検索） |

### CLIオプション

| フラグ | 短縮形 | 説明 | デフォルト |
|--------|--------|------|------------|
| --limit | -l | 検索結果の表示件数を制限 | 無制限 |

### データベースクエリ

```sql
SELECT * FROM logs
WHERE task_name LIKE '%keyword%'
   OR problem LIKE '%keyword%'
   OR solution LIKE '%keyword%'
   OR learning LIKE '%keyword%'
ORDER BY created_at DESC;
```

### エラーハンドリング

| エラー | 対応 |
|--------|------|
| キーワード未指定 | 使い方を表示（exit 1） |
| DB接続失敗 | エラーメッセージを表示して終了（exit 1） |
| 検索結果なし | 「該当する記録がありません」と表示 |
