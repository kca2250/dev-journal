# 検索機能 (djou search)

キーワードで開発日誌を検索する機能。

## コマンド

```bash
djou search "キーワード"
djou search "CORS" "エラー"          # 複数キーワード（AND検索）
djou search "API" --limit 5          # 件数制限
djou search "API" --tag "project:A"  # タグフィルター
djou search "API" --detail           # 詳細表示モード
```

## 機能要件

### FR-1: キーワード検索

以下のフィールドからキーワードを検索する。

- タスク名 (task_name)
- メモ (memo)

### FR-2: 部分一致検索

- 大文字・小文字を区別しない
- 部分一致で検索
- **複数キーワード**: スペース区切りで複数キーワードを指定した場合はAND検索（全キーワードを含む記録のみマッチ）

### FR-3: 検索結果の表示

マッチした記録をテーブル形式で表示する。

| カラム | 説明 |
|--------|------|
| 日付 | 記録日 |
| タスク | タスク名 |
| マッチ箇所 | どのフィールドでマッチしたか（タスク名、メモ） |

### FR-4: 詳細表示 (--detail)

`--detail` フラグで全フィールド（ID、日付、タスク、見積、実績、メモ、タグ）をテーブル表示する。

### FR-5: 検索結果の件数制限

- デフォルトは無制限
- `--limit` オプションで表示件数を制限可能

### FR-6: タグフィルター (--tag)

- 指定したタグを含む記録のみを検索対象とする

## 技術仕様

### コマンド引数

| 引数 | 必須 | 説明 |
|------|------|------|
| keyword | ⭕ | 検索キーワード（スペース区切りで複数指定可、AND検索） |

### CLIオプション

| フラグ | 短縮形 | 説明 | デフォルト |
|--------|--------|------|------------|
| --limit | -l | 検索結果の表示件数を制限 | 無制限 |
| --tag | - | タグでフィルタリング | - |
| --detail | -d | 詳細表示モード | - |

### データベースクエリ

```sql
SELECT * FROM logs
WHERE (task_name LIKE '%keyword%'
   OR memo LIKE '%keyword%')
ORDER BY created_at DESC;
```

### エラーハンドリング

| エラー | 対応 |
|--------|------|
| キーワード未指定 | 使い方を表示（exit 1） |
| DB接続失敗 | エラーメッセージを表示して終了（exit 1） |
| 検索結果なし | 「該当する記録がありません」と表示 |
