# 一覧表示機能 (djou list)

記録した開発日誌を一覧表示する機能。

## コマンド

```bash
djou list              # 直近の記録を表示（対話モード）
djou list --week       # 今週の記録
djou list --month      # 今月の記録
djou list --tag "project:案件A"  # タグでフィルタリング
djou list --no-interactive       # 非対話モード（テーブル表示のみ）
```

## 機能要件

### FR-1: デフォルト表示

オプションなしの場合、直近10件の記録を表示する。

**件数指定**: `--limit` オプションで表示件数を変更可能（デフォルト10件）

### FR-2: 週間フィルター (--week)

- 今週（月曜日〜日曜日）の記録を表示
- ロケールに応じた週の開始日を使用

### FR-3: 月間フィルター (--month)

- 今月（1日〜末日）の記録を表示

**オプション競合**: `--week` と `--month` を同時に指定した場合はエラーを表示（排他的オプション）

### FR-4: テーブル形式での表示

以下のカラムをテーブル形式で表示する。

| カラム | 説明 | フォーマット |
|--------|------|--------------|
| 日付 | 記録日 | YYYY-MM-DD |
| タスク | タスク名 | 最大20文字で省略 |
| 見積 | 見積もり時間 | X.Xh |
| 実績 | 実績時間 | X.Xh |

### FR-5: ソート順

- 日付の降順（新しい順）で表示

### FR-6: タグフィルター (--tag)

- 指定したタグを含む記録のみ表示

### FR-7: インタラクティブモード

デフォルトでは対話モードで表示され、ログを選択して以下の操作が可能：

- **編集**: 選択したログの内容を編集
- **削除**: 選択したログを削除（確認あり）
- **キャンセル**: 一覧に戻る

`--no-interactive` フラグで非対話モード（テーブル表示のみ）に切り替え可能。

## 出力例

```
┌────────────┬──────────────────┬──────┬──────┐
│ 日付       │ タスク           │ 見積 │ 実績 │
├────────────┼──────────────────┼──────┼──────┤
│ 2025-01-10 │ ログイン画面実装 │ 2.0h │ 3.0h │
│ 2025-01-10 │ API連携          │ 1.5h │ 1.5h │
│ 2025-01-09 │ 環境構築         │ 1.0h │ 2.0h │
└────────────┴──────────────────┴──────┴──────┘
```

## 技術仕様

### CLIオプション

| フラグ | 短縮形 | 説明 | デフォルト |
|--------|--------|------|------------|
| --week | -w | 今週の記録を表示 | - |
| --month | -m | 今月の記録を表示 | - |
| --limit | -l | 表示件数を指定 | 10 |
| --tag | - | タグでフィルタリング | - |
| --no-interactive | - | 非対話モード（テーブル表示のみ） | - |

**注意**: `--week` と `--month` は排他的オプション。同時指定時はエラー

### データベースクエリ

```sql
-- デフォルト（直近10件）
SELECT * FROM logs ORDER BY created_at DESC LIMIT 10;

-- 週間
SELECT * FROM logs
WHERE created_at >= [週の開始日] AND created_at < [週の終了日]
ORDER BY created_at DESC;

-- 月間
SELECT * FROM logs
WHERE created_at >= [月の開始日] AND created_at < [翌月の開始日]
ORDER BY created_at DESC;

-- タグフィルター
SELECT * FROM logs
WHERE tags LIKE '%tag%'
ORDER BY created_at DESC;
```

### エラーハンドリング

| エラー | 対応 |
|--------|------|
| DB接続失敗 | エラーメッセージを表示して終了（exit 1） |
| 記録なし | 「記録がありません」と表示 |
| --week と --month の同時指定 | エラーメッセージを表示して終了（exit 1） |
