# 一覧表示機能 (djou list)

記録した開発日誌を一覧表示する機能。

## コマンド

```bash
djou list              # 直近の記録を表示
djou list --week       # 今週の記録
djou list --month      # 今月の記録
```

## 機能要件

### FR-1: デフォルト表示

オプションなしの場合、直近10件の記録を表示する。

**件数指定**: `--limit` オプションで表示件数を変更可能（デフォルト10件）

### FR-2: 週間フィルター (--week)

- 今週（月曜日〜日曜日）の記録を表示
- ロケールに応じた週の開始日を使用

### FR-3: 月間フィルター (--month)

- 今月（1日〜末日）の記録を表示

**オプション競合**: `--week` と `--month` を同時に指定した場合はエラーを表示（排他的オプション）

### FR-4: テーブル形式での表示

以下のカラムをテーブル形式で表示する。

| カラム | 説明 | フォーマット |
|--------|------|--------------|
| 日付 | 記録日 | YYYY-MM-DD |
| タスク | タスク名 | 最大20文字で省略 |
| 見積もり | 見積もり時間 | X.Xh |
| 実績 | 実績時間 | X.Xh |
| AI活用 | AI活用時間 | Xmin（0分の場合は `-` と表示） |

### FR-5: ソート順

- 日付の降順（新しい順）で表示

## 出力例

```
┌────────────┬──────────────────┬──────────┬────────┬─────────┐
│ 日付       │ タスク           │ 見積もり │ 実績   │ AI活用  │
├────────────┼──────────────────┼──────────┼────────┼─────────┤
│ 2025-01-10 │ ログイン画面実装 │ 2.0h     │ 3.0h   │ 30min   │
│ 2025-01-10 │ API連携          │ 1.5h     │ 1.5h   │ 20min   │
│ 2025-01-09 │ 環境構築         │ 1.0h     │ 2.0h   │ 45min   │
└────────────┴──────────────────┴──────────┴────────┴─────────┘
```

## 技術仕様

### CLIオプション

| フラグ | 短縮形 | 説明 | デフォルト |
|--------|--------|------|------------|
| --week | -w | 今週の記録を表示 | - |
| --month | -m | 今月の記録を表示 | - |
| --limit | -l | 表示件数を指定 | 10 |

**注意**: `--week` と `--month` は排他的オプション。同時指定時はエラー

### データベースクエリ

```sql
-- デフォルト（直近10件）
SELECT * FROM logs ORDER BY created_at DESC LIMIT 10;

-- 週間
SELECT * FROM logs
WHERE created_at >= [週の開始日] AND created_at < [週の終了日]
ORDER BY created_at DESC;

-- 月間
SELECT * FROM logs
WHERE created_at >= [月の開始日] AND created_at < [翌月の開始日]
ORDER BY created_at DESC;
```

### エラーハンドリング

| エラー | 対応 |
|--------|------|
| DB接続失敗 | エラーメッセージを表示して終了（exit 1） |
| 記録なし | 「記録がありません」と表示 |
| --week と --month の同時指定 | エラーメッセージを表示して終了（exit 1） |
